# 🎁 Gift Wishlist (React + Framer Motion)

A beautifully animated and responsive wishlist app built with **React** and **Framer Motion**, designed for managing gift ideas with an elegant UI and smooth animations.

---
## 🌟 Demo

🎥 **Live Demo:** (https://adellepresents.netlify.app/) 

## ✨ Features

- 🎨 **Responsive Grid Layout** – Automatically adapts cards for desktop, tablet, and mobile screens.  
- 🖱️ **Smooth Animations** – Framer Motion-driven fade-in and staggered card entrance effects.  
- 🖋️ **Gift Management** – Add, edit, delete, and highlight gift items.  
- 🔗 **GraphQL API Integration** – Powered by **Hasura** for instant CRUD operations.  
- 🔒 **Real-Time Updates** (optional with Hasura subscriptions).  
- ⚡ **Clean, Modern UI** – Intuitive design for a seamless experience.

---

## 🛠️ Tech Stack

- **Frontend:**
  - [React](https://react.dev/) (Hooks-based architecture)
  - [Framer Motion](https://www.framer.com/motion/) (Animation library)
  - [CSS Flexbox/Grid](https://developer.mozilla.org/en-US/docs/Learn/CSS/CSS_layout/Flexbox) for layout

- **Backend:**
  - [Hasura](https://hasura.io/) (GraphQL engine for instant APIs)
  - [GraphQL](https://graphql.org/) (Query language for APIs)

- **Other Tools:**
  - Node.js & npm/yarn
  - Deployment: [Netlify](https://www.netlify.com/)
